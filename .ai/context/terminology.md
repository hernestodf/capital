# Glossário do domínio
- **PPPoE**: Protocolo de autenticação para acesso à internet
- **Bloqueio**: Desativação temporária do serviço por atraso
- **Plano**: Pacote de velocidade/serviço contratado pelo cliente
- **Vencimento**: Data de vencimento do boleto
- **Secret**: Senha/RADIUS para autenticação MikroTik
- **Produtor**: Colaborador que produz eventos
- **Evento**: Ocorrência registrada no sistema (presença, devolução, etc.)
