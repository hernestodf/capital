# Stack
- PHP >= 8.0 (procedural/OO híbrido)
- Framework: ConectaFramework (custom MVC)
- Frontend: Tailwind CSS, Bootstrap legado
- Banco: MySQL (mysqli procedural)
- Servidor: Apache
- Integrações: MikroTik RouterOS, MailJet, IMAP, WhatsApp API (profoxnetworks.com.br)
- Armazenamento: PHPExcel, mPDF para relatórios
