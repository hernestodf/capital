# project_summary
## Sisloc - Sistema de Inteligência Persistente
- **Objetivo**: Gestão de relacionamento com clientes ISP (fibra acesso)
- **Domínio**: Contas a pagar, clientes, produtores, eventos, colaboradores
- **Integrações críticas**: MikroTik (PPPoE/bloqueio), WhatsApp API, MailJet (cotações), IMAP
- **Stack**: PHP 8.0+, MySQL, Apache, Tailwind CSS
- **Status**: Bootstrap .ai/ concluído, aguardando descoberta completa
